How to review these wireframes (v2)

This is version 2, updated after the first review round with the Product Owner, Jean and Lilly. Every decision taken after that round has an ID in docs/decisions.md (for example P21 = the classic tab bar). Each screen shows the sprint that builds it (S3) and, where relevant, a small Changed in v2 · P21 or New in v2 · P32 badge with the decision behind it. Screens without a badge are the same as in v1.

Low-fidelity, grayscale, mobile-first (PWA). Phones are 375×760; screens with a dashed fold line show the full scroll length. Every screen has a stable ID (e.g. B1) and numbered pins, so you can write "B1 pin 3: …". How to give feedback: type in the box under any screen, answer the open questions at the end of each section (For product owners / For possible end users; skip what you have no opinion on), then use Send your feedback at the bottom. Your notes stay in this browser, so you can stop and come back later. Sample content is neutral ("Book title", "@username"); numbers are illustrative only.
