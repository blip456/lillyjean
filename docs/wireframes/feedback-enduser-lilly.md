## Processing notes

Added by the development team. These do not change the feedback above.

### New themes from Lilly

1. **Bookclubs questioned as a concept.** "No need for book club" (`F-U1`), "Not convinced" (`F1`), "Not sold
   on the idea of book club if there is no chat option" (`A12`), and the general remark that bookclubs "can be
   scratched and be replaced by the option to add a note to a book".
2. **Share with friends instead of clubs** (`C2`, `C-PO3`: recommend to anyone with an account).
3. **Notes on books, shareable with others** (`B3`, `D4`, general): a favourite scene or the reason for a
   recommendation. Jean also liked the note option on `B3`.
4. **Challenge indicator on books** (`B1`): an icon when a book you are reading is part of a challenge. This
   matches the Product Owner's request on `D1`.
5. **Simplicity and speed first** (`N-U1`, general): visible buttons over gestures (`I-U1`).

### Consensus across all three

Library card onboarding (`A9`), choose the username right away, email + password sign-in, neutral message
for existing emails, books-only yearly goal that can be adjusted, fixed Home order, three statuses shown next
to readlists (`C1`), club members can (be allowed to) add books to a shared readlist, manual book entry in v1,
re-reads count, books must be finished after the challenge start, no late completion, no notifications inbox,
no social-media sharing, phone first.

Agreed by both end users, not explicitly answered by the Product Owner: missed challenges disappear instead of
showing in "Past" (`E-PO5`, `E-U3`), picking from the suggested books is preferred over an own pick (`E-U2`),
club activity only needs to be seen when opening the app (`F-U3`).
