How to review these wireframes

Low-fidelity, grayscale, mobile-first (PWA) wireframes. Every screen has a stable ID (e.g. B1) so feedback can be given as "B1 pin 3: ...". Phones are 375×760; screens marked with a dashed fold line show the full scroll length. All main screens are drawn with navigation Alt 1 by default; use the Navigation preview switch in the left column to re-render every main screen with Alt 2. Sample content is deliberately neutral ("Book title", "@username"); numbers are illustrative only.
